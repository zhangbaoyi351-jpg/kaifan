# 开饭啦 · 家庭菜谱与菜单管理

一个无需安装依赖的轻量级响应式网页，适合在手机和电脑浏览器中记录家常菜谱。

## 当前功能

- 内置 8 道示例菜谱，支持分类和关键词搜索
- 查看食材、调料用量与烹饪步骤
- 调整用餐人数并按比例换算数字用量
- 收藏菜谱
- 管理今日菜单
- 根据今日菜单汇总采购清单，并勾选已采购项目
- 添加和删除自定义菜谱
- 响应式布局，适配手机与桌面屏幕

## 如何使用

1. 打开仓库中的 `index.html`。
2. 下载文件到电脑。
3. 双击 `index.html`，使用现代浏览器打开即可；不需要安装依赖或启动后端服务。

## 数据保存说明

自定义菜谱、收藏、今日菜单和采购勾选状态保存在当前浏览器的 `localStorage` 中。这意味着数据通常只存在于当前浏览器/设备，不会自动同步到另一台设备，也没有云端备份。清除浏览器站点数据可能导致这些记录丢失，重要菜谱请另行备份。

## 公开访问与部署

仓库目前是私有仓库。网页代码已提交，但网站尚未部署。可以在 GitHub 仓库的 **Settings → Pages** 中配置发布。请注意：GitHub Pages 发布出来的网站可能是公开可访问的，即使源代码仓库是私有的；发布前不要在其中放入隐私信息。是否能从私有仓库发布，取决于 GitHub 账户/组织方案和设置。

## 技术

纯 HTML、CSS、JavaScript，无框架、无外部运行时依赖。
